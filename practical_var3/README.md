# Практична частина: синтез автомата Мілі (варіант 3) у Logisim Evolution

Програма: **Logisim Evolution 5.0.0** (`logisim-evolution-5.0.0-all.jar`, офіційний реліз з GitHub), Java 21.
Потрібна Java 11+ (для 5.0.0 краще 21). Запуск: `java -jar logisim-evolution-5.0.0-all.jar avtomat_var3.circ`.

## Розташування на схемі

- Зліва вертикальна шина: x1, nx1, x2, nx2, Q1, nQ1, Q2, nQ2 (підписи над шиною).
- Смуги зверху вниз: інвертори входів (DD1.1, DD1.2) → T1 (DD1.3, DD1.4, DD2.1–DD2.3) →
  T2 (DD2.4, DD3.1–DD3.4) → y1 (DD4.1–DD4.3) → y2 (DD4.4, DD5.1–DD5.4, DD6.1).
- Праворуч тригери DD7 (T1 → Q1) і DD8 (T2 → Q2), спільні C і R знизу; виходи y1, y2 і контрольні T1, T2, Q1, Q2 — справа.
- Зворотні зв'язки Q1, nQ1, Q2, nQ2 ідуть угору й зверху повертаються на шину.

### Зауваження щодо відповідності курсовій

1. **Підписи `DD1_1` замість `DD1.1`.** Logisim Evolution 5 дозволяє в атрибуті Label лише імена виду
   `[A-Za-z][A-Za-z0-9_]*`. Мітку з крапкою він при відкритті сам перейменовує (`DD1_1_06610899`), вимкнути це не можна.
   Тому крапку замінено підкресленням: `DD1_1` … `DD6_1`, `DD7`, `DD8` — позначення ті самі. У тексті курсової можна
   додати: «у середовищі Logisim позначення DDx.y записано як DDx_y через обмеження на символи в мітках».
2. У DD2.1 і DD3.2 сигнал a1/b1 подано на верхній вхід, а x2/x1 — на нижній (у списку навпаки). NOR комутативний, тож
   логіка і склад з'єднань ті самі, а проводи не перетинаються.
3. Над шиною й над смугами є текстові підписи (Text). Це лише написи, не логічні елементи: `--tty stats` їх не рахує.

## Як перевірялося

- **Тестова послідовність:** скидання R → стан 00, далі 12 тактів. Для кожного такту подається x1x2, читаються y1y2
  (до фронту), потім передній фронт C, читається Q1Q2 (після). Збіглися **12 з 12**.
- **Статика (без такту):** для кожного з 4 станів подано всі 4 вхідні набори. Перевірено T1, T2, y1, y2 і вихід
  кожного з 21 NOR (336 значень) щодо списку з'єднань і формул МКНФ, а також 10 переходів таблиці (новий стан = Q⊕T).
  Збіглися **10 з 10**, внутрішні вузли теж усі.
- Перевірка ловить помилки: якщо видалити один провід (d3 до DD6.1), збігається лише 6 тактів з 12.
- Логіку рахує сам симулятор Logisim 5.0.0 (класи з його .jar). Режим `--tty table` для цієї схеми не підходить:
  він перебирає входи як для комбінаційної схеми і не вміє подавати послідовність тактів.

## Скріншоти вручну (якщо треба перезняти в Logisim)

### а) Уся схема — File › Export Image

1. Відкрийте `avtomat_var3.circ`.
2. **File › Export Image…**
3. У діалозі: Circuits — `avtomat_var3`; Image Format — **PNG**; Scale Factor — 2 (або більше, для чіткості у Word);
   **Printer View** — увімкнути (біле тло, чорні лінії, без кольорів стану). Натисніть OK і виберіть файл.
4. Заголовків на картинці немає: Export Image малює лише схему, без рамки вікна. Якщо щось зайве потрапило —
   виділіть і видаліть Text-підписи перед експортом.
5. Відомий недолік 5.0.0: у Printer View можуть зникнути підписи DD7/DD8 (малюються білим). Тоді або експортуйте
   без Printer View, або візьміть готовий `screenshots/scheme_avtomat_var3.png`: у ньому це вже виправлено.

### б) Часові діаграми — Simulate › Timing Diagram

1. **Simulate › Reset Simulation** (Ctrl+R), переконайтеся, що **Simulate › Auto-Propagate** увімкнено.
2. **Simulate › Timing Diagram** → кнопка **Add or Remove Signals** → залиште R, C, x1, x2, Q1, Q2, T1, T2, y1, y2
   у цьому порядку (стрілками), інші приберіть.
3. Знаряддям «Рука» (Poke Tool, Ctrl+1) клацайте піни на схемі:
   - R: 0 → 1 → 0 (скидання в 00); x1x2 виставте на вхід 1-го такту.
   - Для кожного з 12 тактів: C = 1 (передній фронт), потім C = 0 і одразу виставте x1, x2 для наступного такту.
     Послідовність x1x2: 00, 01, 01, 00, 01, 10, 10, 00, 11, 01, 00, 00.
4. Колесом миші над діаграмою (або кнопками масштабу) підберіть масштаб, щоб усі 12 імпульсів C влізли у вікно.
5. Знімок: у вікні діаграми **File › Export Image** (якщо є у вашій збірці), інакше системний скриншот
   (Windows: Win+Shift+S; macOS: Cmd+Shift+4).
6. Як читати: y1y2 — значення на інтервалі C = 0 перед кожним переднім фронтом; Q1Q2 — значення після фронту.
